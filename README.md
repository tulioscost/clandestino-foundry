# CLANDESTINO — Foundry VTT (Sistema)

Este repositório contém:
- `systems/clandestino/` — sistema do Foundry (ficha corporativa responsiva + rolagem)
- `modules/clandestino-content/` — módulo utilitário (cria macro de teste)

## Instalação (manual)
Copie:
- `systems/clandestino` → `FoundryVTT/Data/systems/`
- `modules/clandestino-content` → `FoundryVTT/Data/modules/`

No Foundry:
1. Reinicie
2. Selecione o sistema **clandestino** no mundo
3. Ative o módulo **clandestino-content**
4. Use a macro **CLANDESTINO | Teste (Dialog)**

## Estrutura da ficha
A sheet padrão do tipo `character` é a **Ficha Corporativa (Funcionário)**:
- responsiva
- espaço para foto/ID
- layout “arquivo corporativo”
