# CLANDESTINO — Ficha Corporativa (Funcionário)

Módulo para Foundry VTT que adiciona uma ficha responsiva estilo **arquivo de funcionário** (com foto/ID)
para o sistema **CLANDESTINO**.

## Instalação
Copie `modules/clandestino-employee-sheet` para `FoundryVTT/Data/modules/` e ative o módulo no mundo.

## Como usar
1. Abra um personagem (Actor do tipo `character`)
2. Clique em **Sheet Configuration**
3. Selecione **Ficha Corporativa (Funcionário)**

> O módulo **não** força a ficha como padrão (para evitar quebrar outras sheets).  
> Se quiser tornar padrão, eu posso te mandar uma versão com `makeDefault: true`.
